# Fun with Video Games and the First Steps of My Journey in UX Design

##  Overview
Basic C++ console apllication with a basci banner and questions to user about gaming information. SOme of those questions include their favorite video game, character, platform, age, and more.
It calculates simple statistics like the *value per hour played* and presents the results in a neatly formatted table on-screen and in a `report.txt` file.

##  Features
-  **Friendly introduction banner** with Windows console colors  
-  **User input** for multiple data types (`string`, `int`, `double`)  
-  **Calculations:**  
  - Age comparison  
  - Game value per hour  
-  **Formatted report output** to console and `report.txt` file  
-  **Menu system** using `switch`  
-  **Input validation** using `if` and `cin.fail()` checks  
-  **Compound Boolean conditions** (`&&`, `||`)  


##  Concepts Demonstrated
- Input/output using `cin` and `cout`
- String handling with `getline()`
- Conditional statements (`if`, `else if`, `switch`)
- Compound logic (`&&`, `||`)
- File output with `ofstream`
- Output formatting using:
  - `setw()`
  - `setprecision()`
  - `fixed`, `left`, and `right`
- Constants and descriptive variable names
- Code documentation with inline comments
- Clean and readable console output
